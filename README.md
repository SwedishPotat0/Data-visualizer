# Data visualizer

This is a terminal based data visualizer that can visulize datapoints on the positive axises on a coordinate system.

## How to use

The datapoints is loaded into the system thru a textfil following the format x y on row for each datapoint. The first row of the file is dedicated for configure info for the coordinate system, such as x and y axis scale.

### Example input data

```
15 15
0 0
5 5
6 8
10 5
```
